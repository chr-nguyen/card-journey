# Card Journey

A three-lane deck-building card battler for Game Boy Color. The playable
prototype features three mountain opponents, color connections, shape-based
combat roles, and FIGHT / GIVE / TAKE abilities. Save one unused card between
turns, then replace a card in your ten-card deck after a win to shape the next
duel.

See [the game rules and build instructions](gbc-c/README.md) and
[the implementation plan](IMPLEMENTATION_PLAN.md).
